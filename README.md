# ⌨️ Typer

Минималистичный тренажёр слепой печати на чистом JS.

## ✨ Возможности
- WPM и точность в реальном времени
- Подсветка ошибок
- Рекорд сохраняется в localStorage
- Тёмная / светлая тема
- Никаких зависимостей, никакого бэкенда

## 🚀 Демо
[Открыть на GitHub Pages](https://username.github.io/typer)

## 📦 Локальный запуск
Просто открой `index.html` в браузере.
